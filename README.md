## Quick Deploy - Web App (Vercel)
1. Fork or clone this repo
2. Go to vercel.com → New Project → Import this GitHub repo
3. Set root to `web-app`
4. Deploy (free tier)
5. Add custom domain later
6. Integrate Stripe Checkout for payments (see Stripe docs)
7. For AI: Replace mock in script.js with OpenAI fetch (API key in env)
